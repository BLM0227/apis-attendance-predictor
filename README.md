# Predicting School Attendance Among Filipino Children and Youth (Ages 5–24), APIS 2022

DS012 / DSA31S1 Machine Learning final project · SDG 4: Quality Education · Stakeholder: DepEd and education policymakers.

A Streamlit app that presents three trained classifiers (Logistic Regression, Decision Tree, Gaussian Naive Bayes),
their validation and held-out test evidence, and lets a user pick a model, enter a profile, and receive a prediction with a
stakeholder-oriented interpretation. **Recommended model: Logistic Regression**, a candidate for further validation and not
approved for deployment.

## App pages
1. **Overview**: SDG, stakeholder, objective, dataset summary, responsible-use note
2. **Models & Evaluation**: model descriptions, CV evidence, held-out test results, confusion matrices, generalisation,
   threshold trade-off, subgroup recall (with sample sizes), recommendation rationale
3. **Prediction**: model selector and threshold in the sidebar, validated input form, result + interpretation,
   optional all-model comparison
4. **Limitations & responsible use**

## Evaluation protocol (leakage-safe)
1. One household-grouped, stratified split (`StratifiedGroupKFold`, `random_state=42`, first fold) → train / test.
2. 5-fold grouped CV **on the training split only** → model comparison, out-of-fold probabilities.
3. Operating threshold chosen on the **out-of-fold** predictions (best not-attending F1 over 0.20–0.80).
4. Final models fitted on the full training split and **scored once on the test split**; subgroup results come from that run.
Preprocessing sits inside each scikit-learn `Pipeline`, so it is refitted per CV fold and never on user input.
All numbers shown in the app are read from `models/evidence.json`, generated by `train_models.py`.

## Folder structure
```
app.py                  Streamlit app
train_models.py         Trains models, runs the evaluation protocol, writes models/ artifacts + evidence.json
export_evidence.py      Exports evaluation tables (CSV) and figures (PNG) to assets/evidence/
requirements.txt
data/                   data_dictionary.md (+ place the APIS CSV here; not committed)
models/                 *.joblib pipelines, metadata.json, evidence.json
notebooks/              model_development.ipynb (Lab 04 notebook)
src/                    config, pipeline, evaluation, evidence, prediction, interpretation, plots, ui
assets/evidence/        saved evaluation tables and figures
documentation/          place the final report here
```

## Setup and run
Requires Python 3.11+.
```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
# put APIS_PUF_2022_Integrated_Cleaned.csv in data/ (see data/data_dictionary.md)
python train_models.py        # only needed to regenerate artifacts (they are already included)
python export_evidence.py     # optional: refresh assets/evidence/
streamlit run app.py
```

## Deployment (Streamlit Community Cloud)
1. Commit `models/` (small) so the hosted app can load the pipelines and evidence; do **not** commit the raw CSV.
2. Push to GitHub, then at https://share.streamlit.io select the repo, branch and `app.py`.
3. Deployed URL: **https://apis-attendance-predictor.streamlit.app/**

## Notes
- Artifacts were trained with scikit-learn 1.8.0 (pinned). The app warns if the installed version differs.
- The split is produced by `StratifiedGroupKFold`; its assignment can differ between scikit-learn versions, so
  results can differ slightly from the Lab 04 report (e.g. test accuracy 91.09% here vs 91.29% in the report).
  Regenerate all report figures from `models/evidence.json` / `assets/evidence/` for consistency.
- The chosen threshold is a candidate operating point, not a stakeholder-approved setting.

## Troubleshooting
- *"models/evidence.json was not found"*: run `python train_models.py`.
- *Version warning*: install the pinned scikit-learn or retrain.
- *Form options look wrong*: they are read from the training data into `models/metadata.json`; retrain after changing data.
